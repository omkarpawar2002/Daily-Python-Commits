# Operators in Python

## Overview

I learned about **Operators** in Python.

Operators are used to perform operations on variables and values such as calculations, comparisons, logical decisions, and value assignments.

Operators are essential for building logic in programs and are heavily used in conditions, loops, functions, and real-world applications like calculators, validation systems, and data processing.

# Topics Covered

## Arithmetic Operators

Used to perform mathematical calculations.

Operators learned:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Floor Division (//)
* Modulus (%)
* Exponent (**)

---

## Comparison Operators

Used to compare values.

Result of comparison is always:

* True
* False

Operators learned:

* Equal (==)
* Not Equal (!=)
* Greater Than (>)
* Less Than (<)
* Greater Than or Equal (>=)
* Less Than or Equal (<=)

---

## Logical Operators

Used to combine multiple conditions.

Operators learned:

* and
* or
* not

---

## Assignment Operators

Used to assign and update values.

Operators learned:

* =
* +=
* -=
* *=
* /=
* //=
* %=
* **=

Used to:

* update variable values
* simplify mathematical operations

---

## Identity Operators

Used to compare memory location of objects.

Operators learned:

* is
* is not

Used when checking whether two variables refer to the same object.

---

## Membership Operators

Used to check whether a value exists in a sequence.

Operators learned:

* in
* not in
