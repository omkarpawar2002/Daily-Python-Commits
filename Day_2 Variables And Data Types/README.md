# Variables and Data Types (Python)

## Overview

I learned the fundamental concepts of **Variables** and **Data Types** in Python.

These concepts help in storing, managing, and identifying different types of data in a program. Understanding variables and data types is essential before moving to logic building topics like conditions, loops, and functions.

---

# Topics Covered

## Variables

* What is a variable
* Rules for naming variables
* Valid vs invalid variable names
* Dynamic typing
* Assigning values
* Multiple assignment
* Reassigning variables

---

## Data Types Overview

Python provides different built-in data types to store various kinds of data.

### Categories learned:

* Numeric types
* Boolean type
* Sequence types
* Mapping type
* Set type
* None type

---

## Numeric Types

Used to store numbers.

* int → whole numbers
* float → decimal numbers
* complex → numbers with real and imaginary parts

---

## Boolean Type

Used for logical values:

* True
* False

Commonly used in decision making and conditions.

---

## Sequence Types (Introduction)

Used to store multiple values in order.

* string
* list
* tuple

---

## Mapping Type (Introduction)

Stores data in key-value pairs.

* dictionary

---

## Set Type (Introduction)

Stores unique values.

* removes duplicate values automatically

---

## None Type

Represents absence of value.

Used when a variable has no data assigned yet.

---

## Type Checking

Functions used:

* type() → checks data type of a variable
* id() → returns memory reference of variable
