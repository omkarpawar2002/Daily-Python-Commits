# Type Casting & Input Output (Python)

## Overview

I learned how Python handles **type conversion**, **user input**, and **output formatting**.

These concepts allow programs to interact with users, process different data types correctly, and display output in a readable format.

Understanding input and output is essential for building interactive applications such as calculators, login systems, and form-based programs.

---

# Topics Covered

## Type Casting

Type casting means converting one data type into another.

### Types of casting learned:

* Implicit casting (automatic conversion by Python)
* Explicit casting (manual conversion by programmer)

### Casting functions learned:

* int() → converts value to integer
* float() → converts value to decimal number
* str() → converts value to string
* bool() → converts value to True or False

---

## User Input

Programs often need input from users.

### Functions learned:

* input() → takes input from user (default type is string)
* Converting user input into required data type

---

## Output Formatting

Used to display results in structured way.

### Functions and parameters learned:

* print() → displays output
* sep parameter → changes separator between values
* end parameter → changes what prints at end of line
